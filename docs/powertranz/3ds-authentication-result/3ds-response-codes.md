#### **3DS Response Code**(RiskManagement.ThreeDSecure.ResponseCode)

The **3DS ResponseCode is generated by Powertranz** which shows the final status of the 3DS authentication.

| **ResponseCode** | **3DS Response**             | **Description**                 | **Notes**                           |
| ---------------- | ---------------------------- | ------------------------------- | ----------------------------------- |
| 3D0              | Authentication Complete      | 3DS Complete                    | 3DS2 process complete               |
| 3D1              | Authentication not available | 3DS not supported for card type | Pre-authentication process complete |
| 3D3              | Authentication Error         | 3DS Error                       | 3DS2 error                          |

> 📘
>
> ### **Good to Know**
>
> **"3D0"** means the process was completed successfully. However, the detailed results still need to be interpreted and a decision should be made before determining whether or not to send a payment completion.

> 📘
>
> ### **Note !**
>
> By default, payment completion will be allowed only if the 3DS Authentication is successful (3D0 with Y or A authentication status) or 3D1 (considered non-3DS)
