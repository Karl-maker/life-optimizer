# Refunds and credit notes

`billing.recordRefund` records a **confirmed** provider refund. The calling adapter must first request the refund at Stripe or PowerTranz, or verify its provider event/query; a local call does not send money back. Pass the original local `paymentId`, provider's unique refund reference, positive `amountMinor`, short reason, occurrence time, and `revokeAccess`. The service checks that the payment belongs to the user's account and that cumulative refunds cannot exceed the original payment. Replaying the same reference and amount returns the existing refund. Each successful refund creates one linked credit note with its own local serial number and a snapshot reason/amount.

If `revokeAccess=true`, grants from the invoice are revoked only once cumulative successful refunds across **all** its payments reach the full invoice total. A partial refund leaves access intact. The caller must choose the access policy explicitly; some services should keep access until a period end or use a manual adjustment instead. The revocation and credit note audit/outbox records commit with the refund row. A refund does not rewrite the original invoice or erase usage.

For Stripe, call `stripeAdapter.refundPayment({ paymentIntentId, amountMinor, currency, idempotencyKey, reason })`. It sends an idempotent `/v1/refunds` request and checks that the returned refund ID, PaymentIntent, amount, and currency match. Call `billing.recordRefund` only when Stripe reports `succeeded`; the signed `refund.updated` handler also records a succeeded refund against a known payment and issues its credit note. Set `revokeOnFullRefund` on the sync wrapper if that is the configured access policy. Reconcile `pending`, `failed`, or `canceled` later. Disputed charges and country-specific credit-note tax corrections still need host integrations. PowerTranz's supplied documents identify `/api/refund` but do not give a complete merchant request body linking the original sale, so this package does not send that request. Never infer it from a Swagger field name.
